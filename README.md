## 外贸站到底需要什么样的机器

外贸独立站要同时伺候两类人。一类是目标买家，在欧美或东南亚，他们决定 Google 爬虫怎么抓、Core Web Vitals 拿多少分；另一类是你自己的运营团队，在国内，每天登后台传产品图、看订单、改价格。前者的诉求是页面别转圈，后者的诉求是后台别卡成幻灯片。上传一张 5MB 的产品图等半分钟，这种事经历两次就想换服务器了。

除此之外还有三条硬要求：独立 IP、独享资源、不用备案。境外机器购买后直接部署上线，不走工信部备案流程，这点对赶着上线的独立站很关键。

原生 IP 值不值得为它多付钱，得分开看。Google 排名主要看内容质量和页面性能，IP 是不是原生对排名没有直接作用；原生 IP 真正的用处是降低平台账号的风控概率，比如 Stripe 收款、Facebook 广告账户。这个判断来自第三方测评作者的整理，不是 Akile 的官方说明，但和多数站长的实际经验对得上。做纯展示站可以不为原生 IP 付溢价，做收款和投流的站值得留意套餐页上有没有标"原生 IP"。

## 内存和硬盘：1GB 什么时候够，5GB 为什么是坑

1GB 内存够不够，取决于你怎么装。跑一个轻量 WordPress，配 Nginx 加缓存插件，1GB 能撑住，这是不少站长的实际配置。但如果日均访问到一两千 PV、装了 WooCommerce、开了多语言、插件装了十几个，2GB 才是安全线，否则内存溢出会让站点直接挂掉。

按这个标准回头看表：LAXLite-Mini 和 JPHyper-Lite 都是 1 核 2GB，价格分别是 ¥15.99 和 ¥14.99，是四条线里唯一在这个价位给到 2GB 的。SGLite 全系和 HKLite-Mini 都是 1GB，做纯展示型企业站没问题，上 WooCommerce 就要掂量。

比内存更容易被忽略的是硬盘。LAXLite-One 和 SGLite-One 只有 **5GB SSD**。系统本身占掉一两个 GB，装完宝塔面板、PHP、MySQL、WordPress，再传几十张产品图，5GB 很快就见底。硬盘满了 MySQL 会写不进去，站点直接报错，这种故障排查起来还特别费时间。¥8.88 和 ¥10.42 的入门价看着便宜，实际能用的空间很有限。多花几块钱上 10GB 档，省下的是以后折腾的时间。真要放大量产品图，20GB 的 JPPro 系列或者干脆把图片放对象存储更合适。

操作系统选 Linux，Debian、Ubuntu、AlmaLinux 都行，WordPress 和 WooCommerce 跑得最稳，资源占用也低。Windows 只在必须跑 .NET 或者要用远程桌面的时候才考虑，同样的钱买到的配置更低。部署方式两条路：装宝塔面板，图形界面管理站点、数据库、SSL，国内用户上手快；或者命令行自己搭 LNMP，省内存、可控性强，但要会看日志。

## 流量超了会怎样

Akile 早期洛杉矶套餐页上标注的规则是流量用完后限速，不是停机，超出后带宽降到 10Mbps。这个速度跑文字站够用，图片多的站会明显变慢，但至少网站还在线，不会因为某个月做了一次推广就被掐断。

限速阈值和具体数值各型号可能不同，下单页会写清楚，付款前扫一眼那一行。做投放的站要特别留意：一次 Facebook 广告跑起来，2TB 流量可能一周就见底。流量配额和带宽是两件事，5Gbps 的峰值带宽不等于你能随便跑 5TB。
